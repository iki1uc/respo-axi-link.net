# RESPO AXI-Link

Dieses Modul verbindet das RESPO-System mit AXI-fähigen Hardware- oder Software-Komponenten.

## Funktionen
- AXI initialisieren
- AXI prüfen
- AXI lesen
- AXI schreiben
- Router-Hooks senden

## Dateien
- index.html – UI
- ID.html – Modulidentität
- axi-config.json – AXI-Konfiguration
- axi-lage.json – Lage-Daten
- axi-weiser.json – Weiser-Daten
- axi-link.js – AXI-Logik
- router-hook.js – Router-Integration
